# Data Structures and Algorithms — Hash Tables and Graphs

Coursework project covering the practical implementation and analysis of two
fundamental data structures: **hash tables** and **graphs**. Written in Java.

## Overview

The project is split into two parts.

### Part 1 — User Authentication with Hashing

A simulated user authentication system that demonstrates hashing in practice.
The hash table stores usernames, handles collisions, and visualises the hashing
process through ASCII conversion and index mapping.

### Part 2 — Touristic Map System with Graphs

A graph model of local tourist attractions in Carlow, built for a walking tour
application. Graphs are well suited to representing networks of interconnected
locations, and here they support:

- finding connected sites
- inserting new paths
- identifying the nearest attraction

## Purpose

Together, the two parts reinforce the theory while showing how these structures
are applied in real software — from secure login systems to interactive mapping
tools.

## Contents

- Java implementation of both data structures
- Documentation and diagrams
- Written analysis
